## 1. 目标与边界

本任务先把“如何运行、采样、判定和清理”做成可测试工具，再等待硬件完成真实长稳。无硬件时只运行 runner 自测、dry-run 和 20 次短时双总线 Host 回归，不等待 10 分钟、60 分钟或 8 小时来制造硬件稳定性结论。

## 2. 为什么不记录 free heap

项目关闭 FreeRTOS 动态分配，没有链接 `heap_x.c`，linker heap reserve 为 0。这里不存在需要周期追踪的动态 free heap。text/data/bss 是构建期静态事实；运行期主要观察五任务 stack watermark、固定队列水位、任务进度和通信错误计数。

把 Linux 进程 RSS 或一个伪造的 free-heap 数值写进报告，都会混淆主机工具与 STM32 资源，因此 runner 明确禁止这种外推。

## 3. Runner 设计

`tools/soak_runner.py` 只依赖 Python 标准库，默认不访问外设。它支持：

- `--self-test`：验证正常数据和各种 mutant；
- `--dry-run`：显示阶段，但不启动 collector；
- `--host-preflight`：有界重复运行 T04 双总线测试；
- `--evaluate`：离线判定已有 JSONL；
- `--run`：在身份、时长、输出目录和 collector argv 都明确时才启动实物采集。

collector 使用 argv 和 `shell=False`。runner 限制 16 KiB/行、600 个样本和 64 KiB stderr；超时或中断会清理整个子进程组。

## 4. 为什么不能只比较首尾

只看开始和结束，可能漏掉中途队列满、任务短暂停滞或错误持续增长。runner 同时执行：

1. 每个样本的阈值和容量检查；
2. 相邻样本 counter delta；
3. 最多四个时间窗口的水位、watermark 和错误增量；
4. 最后两个窗口的任务和传感器进度检查。

累计 release/accepted 本来就应该增长，不能把所有增长都解释为泄漏。真正的硬失败是容量越界、时间/计数倒退、连续停滞、持续错误增长、复位/fault 或 stack 低于 32 free words。

## 5. 宽松但可执行的结果等级

- `PASS`：没有硬失败和待解释项；
- `REVIEW_REQUIRED`：一次孤立错误、采样缺口、短暂停滞或仍高于 32 words 的 watermark 下降；
- `FAIL`：合同破坏、持续恶化、身份变化、时长不足或 runner/collector 失败。

孤立事件不会被苛刻地直接判死，但正式 PASS 前必须解释，不能静默忽略。

## 6. 实际实施与验证

runner 自测覆盖 20 项有界检查，包括：

- stable PASS；
- boot identity、timestamp 和 counter rollback；
- 五任务（包含 health task）stall、stack 下限和 queue capacity；
- reset/fault 与三窗口连续错误增长；
- malformed、oversized、unknown schema、缺样本/metadata 字段和样本上限；
- 子进程成功、非零退出、超时和清理。

20 次 T04 `p5_host_dual_bus_fault_matrix` 预检全部通过。Host Debug/Release 仍为 21/21；三类合同、ARM 双配置和资源门通过，默认固件没有任何变化。

## 7. 实际问题与修复

首轮 runner 已能正确验证 Schema 和进程超时，但复核发现“collector 返回 0”本身不能证明跑满计划时长。随后增加 `last elapsed >= planned duration - one sample period` 的硬门，并为该边界补充自测。这样可以防止正式 collector 提前退出却被误判为 PASS。

## 8. 证据和硬件下一步

一次真实 session 最多保留分钟级 `samples.jsonl`、`summary.json` 和 `summary.md`。不保存逐 tick trace、持续 candump、串口逐字节日志或重复 CTest 输出。

当前固件内部已有完整快照，但还没有完整的周期外部 sample producer。硬件到货后应先审核 collector，再按 10 分钟 smoke、60 分钟预跑、用户明确授权的 8 小时正式运行推进。真实 stack、jitter、吞吐、复位和恢复趋势在该阶段取得；本轮全部保持 `NOT_RUN`。
